【*】程序简介

-工程名称：ADC-芯片温度
-实验平台: 野火 GDH759IMK6-GD32开发板

-功能简介：
使用ADC的内部温度通道获取芯片温度
通过ADC0的通道18获取芯片内部的温度，把获取到的温度通过串口打印到电脑的串口调试助手显示。


/*********************************************************************************************/

【 ！！】注意事项：

本实验输出的是芯片温度，一般比气温要高
 
【 ！】实验操作：
电脑端使用串口调试助手，选择电脑与GD32相连的COM口，设置为115200-N-8-1，
复位开发板，即可接收GD32串口发送给电脑的数据。

/*********************************************************************************************/


【*】 引脚分配

USART0：
	CH340  RXD  <----->  USART0  TX  (PA9)
	CH340  TXD  <----->  USART0  RX  (PA10)											


/*********************************************************************************************/
		
【&】程序描述：
      
<bsp_usart_debug.h>: 
	
	 1.宏定义所选用的串口、串口的外设时钟、串口时钟使能以及串口的波特率
	 2.宏定义串口有关的GPIO时钟及其时钟使能
	 3.宏定义串口的收发引脚接口
	4.宏定义串口的中断寄存器请求	
					
<bsp_usart_debug.c>:
      
	1.配置USART(其中包括两大部分：GPIO口的初始化和USART的初始化。    
	GPIO口的初始化和前面的一样，这里不赘述。
	USART的初始化：配置波特率、数据字长、停止位、校验位、硬件流控制、工作模式这六个工作参数，
	最后要加上完成配置的程序。此外还要配置串口中断优先级，使能串口接收中断，使能串口
	2.编程发送一个字节、8位数组、字符串、一个16位数的函数体
	3.重定向c库函数printf和scanf到串口
	
<bsp_adc.c>:

-ADC配置

	1. 初始ADC用到的GPIO； 
	2. 设置ADC的工作参数并初始化； 
	3. 设置ADC工作时钟； 
	4. 设置ADC转换通道顺序及采样时间；
	5. 使能ADC的DMA功能；
	6. 使能ADC；
	7. 使能软件触发ADC转换。
